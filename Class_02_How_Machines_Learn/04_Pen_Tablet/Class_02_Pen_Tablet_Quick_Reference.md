## 5. Hero Moments (protect these no matter what)

1. **Drawing #4 — The Core Pipeline.** Full 5–6 min live build, box by
   box, question before each box. Never pre-drawn. Never compressed
   below ~5 minutes.
2. **Cats-vs-Dogs Activity.** Full facilitated sequence — not a
   drawing, but equally protected. Extension round is the only
   compressible part.
3. **The Rule Problem (Drawing #3).** The productive-struggle moment
   that earns the pipeline reveal — never skip straight to Drawing #4
   without it visibly landing.

---

## 6. Do Not Draw / Do Not Introduce

- Python, code, pseudocode, `if/else` syntax
- Neural-network architecture, weights, parameters, layers
- Gradient descent, optimization, loss functions
- Transformers, embeddings, tokens, LLM internals
- Probability, confidence scores, accuracy, precision/recall
- RAG, agents (as a mechanism — the word "Agents" only appears as a
  future staircase-step *label*, never explained)
- Any actual proprietary detail of how a named company's product works
- A finished/pre-drawn version of **any** of the six drawings before
  its live build

## 7. 90-Minute Compression Reminders

- Drawing #1: 3 examples only (spam, recommendations, face unlock).
- Drawing #2: cap rule collection at 3 rules.
- Drawing #3: 3 counter-examples instead of 4 — crowding must still
  visibly land; do not under-compress this one.
- **Drawing #4: unchanged.** Do not trim the hero drawing further if
  behind schedule — cut elsewhere first.
- Cats-vs-Dogs: drop the extension round only; keep the full 8-step
  core sequence.
- Drawing #5 / #6: unchanged build sequence, tighter timing.
- If still over time after Drawing #3: deliver Drawing #5 as a spoken
  map instead of live-drawn — the last permitted cut before touching
  Drawing #4 or the Recap.

## 8. 120-Minute Expansion Reminders

- Extra time → more student reasoning and interaction, **never** new
  technical content or a new drawing.
- Drawing #1: allow a student-suggested 6th example.
- Drawing #3: pace counter-examples out more slowly.
- Drawing #4: same sequence, slower pauses after each question.
- Drawing #5: 1–2 extra "where does X belong?" questions before the
  GenAI marker is placed.
- Drawing #6: only if there's genuine spare room, redraw the
  Traditional-vs-ML comparison next to the staircase instead of
  pointing back to Drawing #4's page.
