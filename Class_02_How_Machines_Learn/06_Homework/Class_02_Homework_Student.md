## What This Assignment Is About

In class, we answered one question:

> **"How can a machine make a decision when nobody explicitly wrote
> the rule for every situation?"**

We saw that writing rules by hand works well when a human can clearly
describe the logic — but becomes difficult once the number of
situations and exceptions grows. We saw an alternative:

```
DATA → LEARNING → MODEL → PREDICTION
```

— give the system examples instead of rules, and let it find useful
patterns on its own. We reasoned through this with a spam filter and
with the cats-vs-dogs activity, and we saw that a prediction is a best
guess, not a guarantee — and that the data behind it matters.

This assignment asks you to **explain these ideas in your own words**
and apply them to something new. There is no coding, no math, and no
single "correct sentence" to memorize — if your reasoning is sound,
your answer is good, even if it doesn't use the exact words from
class.
