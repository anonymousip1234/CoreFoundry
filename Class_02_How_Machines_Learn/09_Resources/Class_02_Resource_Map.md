resources in this folder — so you can see at a glance why each one
exists, and skip straight to it if a moment in class calls for it.

## What This Map Deliberately Leaves Out

- **The Rule Problem** and **Traditional Programming vs. ML** have no
  dedicated external resource — the Student Notes and in-class
  activities already cover these completely, and no external resource
  found during research added anything beginner-appropriate beyond
  what's already there. Forcing a resource into this row would have
  violated "quality over quantity."
- **AI/ML/DL/GenAI** has no resource specifically isolating Generative
  AI at the class's exact simplified altitude — every credible source
  found either stayed too shallow to add value or went straight into
  transformer/LLM architecture. None were included rather than
  stretching one to fit.
- **Face unlock** and **spam detection** (two of the five approved
  AI-Around-Us examples) have no dedicated resource — see
  `Class_02_Student_Resources.md`'s exclusion notes for why the
  candidates found for these didn't clear the bar.

This map is intentionally shorter than the full set of Class 02
concepts — that's the point, not a gap.
