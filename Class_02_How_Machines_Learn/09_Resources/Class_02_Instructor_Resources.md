## Teaching / Pedagogy

Resources that help you explain the class's core ideas, not resources
to hand to students.

### Google PAIR — People + AI Guidebook: "Explainability + Trust"

**Link:** https://pair.withgoogle.com/chapter/explainability-trust/
**Time:** ~15 minutes
**Use for:** Your own understanding of *why* and *how* to communicate
that predictions aren't guarantees — this chapter is written for
people designing AI-powered products, and it's the clearest
professional treatment of "help users build the right mental model of
what a prediction can and can't promise" that maps directly onto
Prediction ≠ Certainty (Instructor Guide §16, Cheat Sheet Card E).

**Not for students:** It discusses probability and model-confidence
display directly — both explicitly deferred from Class 02. Use it to
sharpen *your* explanation, not as assigned reading.

### Code.org — AI for Oceans, Lesson Plan (Teacher View)

**Link:** https://studio.code.org/s/oceans/lessons/1/
**Time:** ~10 minutes to preview
**Use for:** Preview this yourself before pointing students to the
activity (also listed in Student Resources). It's a well-designed
model of teaching "training data → classification → what happens with
bad data" through a hands-on activity — useful as a design reference
if you ever want to compare notes against how this class's own
Cats-vs-Dogs activity (Interaction Pack §7) is structured.

## Conceptual Reference

Consult these if a student asks a question that needs a clean,
credible answer beyond what Class 02 itself teaches — without pulling
the whole class into deferred territory.

### AI4K12.org — "Five Big Ideas in AI"

**Link:** https://ai4k12.org/
**Publisher:** AI4K12 Initiative (jointly run by AAAI and CSTA, NSF-funded)
**Time:** ~10 minutes
**Use for:** A credible, widely-adopted framework for where AI
education is generally structured (Perception, Representation &
Reasoning, Learning, Natural Interaction, Societal Impact). Useful for
your own orientation on where Class 02's "Learning" slice fits into
the broader picture — not something to teach directly.

### IBM Think — "AI vs. Machine Learning vs. Deep Learning vs. Neural Networks"

**Link:** https://www.ibm.com/think/topics/ai-vs-machine-learning-vs-deep-learning-vs-neural-networks
**Time:** ~10 minutes
**Use for:** A ready, credible answer if a student asks "what's the
actual difference?" in more depth than the class's orientation map
covers, or asks "what's a neural network?" in the Advanced-Student
Parking Lot moment. Also listed (with a "skip the Neural Networks
section" note) in Student Resources as optional curiosity.

### Google — Teachable Machine

**Link:** https://teachablemachine.withgoogle.com/
**Time:** ~15 minutes
**Use for:** Building your own hands-on familiarity with
`DATA → LEARNING → MODEL → PREDICTION` before class, so your live
explanations (and answers to student questions about "what would
actually happen if...") are grounded in something you've tried
yourself. **This does not change or replace the approved Pen Tablet
Board Plan** — the live class still builds the pipeline on the pen
tablet exactly as documented; this is prep, not a new classroom tool.

## Future Preparation — NOT FOR CLASS 02

Useful for *your own* deeper understanding of where the curriculum is
headed. Do not bring this material into Class 02 — it belongs to later
stages (Month 3+, per the Instructor Guide's roadmap framing).

### Elements of AI

**Link:** https://www.elementsofai.com/
**Publisher:** University of Helsinki / MinnaLearn (free, ~30 hours total)
**Covers:** Defining AI, search and problem solving, **probability and
Bayes' rule**, machine learning, **neural networks**, societal
implications.
**Why it's future prep, not Class 02 material:** It covers several
explicitly deferred topics (probability, Bayes' rule, neural-network
mechanics) within the first couple of modules. Useful for your own
preparation ahead of the point in the curriculum where the program
returns to these topics with the mathematical foundation to support
them — not appropriate to assign or reference to first-year students
this early.

## How to Use This Document

- Nothing here is required reading for you either — it exists so you
  have a fast, credible answer ready if a question needs one.
- If you use any of the "Conceptual Reference" entries to answer a
  student's question live, keep your answer at the same conceptual
  altitude as the rest of Class 02 — these sources go deeper than you
  need to, on purpose, so you can stop wherever the class's scope
  stops.
