# Class 01 — Welcome to Computer Science

**Program:** Bong Study Hub — Foundation Batch 2026
**Month:** 1 (Foundations)
**Subtitle:** From Using Technology → Understanding Technology
**Duration:** 90–120 minutes (recommended ≈110 minutes)
**Prerequisite:** None

## Purpose

Class 1 is the entry point of the four-month foundation program. It does not
teach Python syntax, hardware architecture, operating systems, DSA, or ML
mathematics. Its only job is to build a first-year student's **mental model**
of what Computer Science and programming actually are, using the narrative:

```
I use technology → What is actually happening? → Computer Science →
Computers execute instructions → Programming gives instructions →
Problems need solutions → Solutions require logic → Logic becomes algorithms →
Algorithms become programs → Programs produce results →
These foundations eventually lead toward AI
```

The class is designed to work for a room where some students have never
opened a terminal and others already know how to code — without boring the
second group or losing the first.
