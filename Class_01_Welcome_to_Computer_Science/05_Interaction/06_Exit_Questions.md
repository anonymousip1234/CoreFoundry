# Class 01 — Exit Questions

**Bong Study Hub — Foundation Batch 2026 · Welcome to Computer Science**

Five short written questions to close the class — distinct from the five
*verbal* recap questions asked live in the last 10 minutes (Guide §11 /
Question Bank §11). Use these as a quick written exit ticket: students
answer in 2–3 sentences each, submitted via chat, a shared form, or paper
if in person. This is a pulse-check, not a graded assessment — there is no
score attached, only whether the class's seven success criteria (Guide
§10) landed.

**How to run it:** Give 4–5 minutes at the very end of class. Ask students
to answer in their own words, in plain sentences — no need for
definitions memorized word-for-word. If time is short (90-minute version),
this can be assigned as the first five minutes of the homework submission
instead of an in-class exit ticket — see Note at the bottom.

---

## Student-Facing Exit Questions

**1.** Is Computer Science the same thing as coding? Explain your answer
in 1–2 sentences.

**2.** Think of something you did in the last hour. What was the input,
what was the process, and what was the output?

**3.** Describe an algorithm for a simple everyday task of your choice, in
at least 3 steps. Which "computational thinking" skill from today did you
use to come up with it — decomposition, pattern recognition, abstraction,
or algorithmic thinking?

**4.** What's the difference between an algorithm and a program?

**5.** How does today's class eventually connect to Artificial
Intelligence?

---

## Instructor Answer Key

*(Not shown to students. Use this to gauge whether the class landed, not
to grade individual answers.)*

**1. CS vs. Coding**
- **Strong answer:** States clearly that coding is one part of Computer
  Science, not the whole field — may name another area (algorithms,
  databases, networks, AI, security).
- **Acceptable answer:** "Coding is part of CS but there's more to it" —
  even without naming a specific other area.
- **Weak / needs follow-up:** "Yes, they're the same" — flag this
  specific student for a quick 1:1 clarification before the next class,
  since this is the single most important reframe of the entire session.

**2. Input → Process → Output**
- **Strong answer:** A coherent, personal triple where all three parts
  are clearly distinguishable (e.g., "message notification [input] → I
  read and decided how to reply [process] → I sent a reply [output]").
- **Acceptable answer:** Input and output are correct but the process is
  vague ("I did something") — this is fine; the process box was
  deliberately left as a "mystery box" today.
- **Weak / needs follow-up:** Only two of the three parts given, or the
  input and output are swapped/confused.

**3. Algorithm + Computational Thinking**
- **Strong answer:** At least 3 genuinely ordered steps for a real task,
  plus a correctly named computational thinking skill that plausibly
  matches how they built it (e.g., decomposition if they broke the task
  into pieces, algorithmic thinking if they focused on the ordered
  steps themselves).
- **Acceptable answer:** The steps are a little vague or the named skill
  is close-but-not-exact (e.g., says "pattern recognition" for what's
  really "algorithmic thinking") — this reflects the genuine overlap
  between the four skills, not a wrong answer.
- **Weak / needs follow-up:** Steps that aren't actually ordered (a list
  of ingredients/items rather than actions), or no computational thinking
  skill attempted at all.

**4. Algorithm vs. Program**
- **Strong answer:** Algorithm = the steps/strategy (language-independent);
  Program = those steps written in a specific programming language. May
  use the recipe/dish analogy.
- **Acceptable answer:** Gets the direction right but phrasing is loose
  ("algorithm is like the plan, program is the real thing").
- **Weak / needs follow-up:** "They're the same" or "algorithm is just
  another word for code" — this is the second most important reframe of
  the class; worth a quick individual note or check-in.

**5. Connection to AI**
- **Strong answer:** States that AI is built on top of programming and
  Computer Science foundations — may reference the staircase or the
  "we build the staircase, we don't jump to the top" line.
- **Acceptable answer:** "AI needs programming to be built" — directionally
  correct even without the staircase language.
- **Weak / needs follow-up:** "AI is unrelated to what we learned today" —
  per Guide §11, this specific misconception should not be left
  uncorrected; if it shows up here, address it explicitly at the start
  of Class 2 rather than only in a written note.

## Note — 90-Minute Version

If the class is compressed to 90 minutes, do not cut this exit ticket —
per Guide §4.3, the final recap is protected content, and this written
version is a low-cost, low-time way to preserve that check even under
time pressure. If literally no time remains, fold it into the first 5
minutes of Assignment 1's submission instructions instead of running it
live: "before you start the homework, answer these five questions about
today's class in your own words."
